## Counter App

A simple counter built with HTML, CSS and JavaScript.

**Live demo:** https://counter-app-shreyash.onrender.com/

### Features
- Increment the count
- Decrement the count
- Reset the count to 0

### Concepts practised
- Selecting elements with `document.getElementById`
- Reading and updating `textContent`
- Converting text to numbers with `parseInt`
- Writing and calling functions from HTML buttons

### Run locally
1. Clone the repo:
   ```bash
   git clone https://github.com/shreyash3062/JavaScript-Practice-.git
   ```
2. Open the `Counter App` folder.
3. Open `index.html` in your browser.
